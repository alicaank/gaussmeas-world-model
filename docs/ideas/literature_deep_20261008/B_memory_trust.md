# Report B — Memory write/read/trust in 3D-memory world models (subagent, 2026-10-08)
V = verified by the agent (paper HTML or code), I = inferred. Base models: Lyra 2.0 = Wan2.1-14B; Mirage/LSM-World and Memorizon = Wan2.2-TI2V-5B; Robust Dreamer/GEAR = Wan2.1-I2V-14B + LoRA.

## A. Render-conditioned systems (memory is the carrier; little or no temporal history)
- GEN3C (2503.03751, nv-tlabs/GEN3C): per-view point clouds, NOT fused, rolling buffer. Write: render existing cache at the new pose, align the new frame's MoGe depth to that render with rigid scale+shift masked by cache validity (or ARAP), unproject, append; depth only on the LAST frame of each chunk. Read: each buffer forward-warped separately -> V renders+masks, max-pooled after an In-Layer. Conflict: cache renders + previous chunk's last frame as a 1-frame latent; inference-time noise on renders scaled by buffer age. Training: cache from 1-4 random GT frames, 15% condition dropout, no depth corruption; 32 A100 ~44 days (SVD version). Camera only via render; TSED 0.914 vs CameraCtrl 0.803. Robustness: 30% depth noise PSNR 24.1 -> 18.5.
- Voyager (2506.04225, Tencent-Hunyuan/HunyuanWorld-Voyager): world cache = colored point cloud from the model's own joint RGB-D output. Write: all points in uncovered regions; in covered regions only if view angle > 90 deg; generated depth trusted as-is, no confidence. Read: RGB+depth render stacked along height + max-pooled mask through zero-init control blocks. Conflict: next segment = cache render + half-segment overlap initialised from the previous result, averaged + re-noised. Training condition = projection of the FIRST frame's cloud only, no corruption. Camera only via render (explicitly avoids pose embeddings). The autoregressive loop and culling are not in the public repo.
- ViewCrafter (2409.02048): DUSt3R cloud rebuilt from all images each iteration, generated depth never used; no recent-frame conditioning. Matrix-3D (2508.08086): single panoramic mesh never updated from generated frames; render+mask concat into Wan2.1-14B LoRA; camera via render.
- MoVerse (2606.13376): fixed panoramic 3DGS scaffold never written; "the scaffold, not the video-model cache, carries long-range consistency"; no numbers. Mirage/LSM-World (2606.09828, microsoft/LatentSpatialMemory, Wan2.2-5B): latent point set, union-only writes outside dynamic/sky masks, no confidence; z-buffered latent warp + visibility mask into a ControlNet side branch; context = 1 clean preceding chunk + I0; fully teacher-forced from GT/ViPE caches; closed-loop PSNR 20.05 / LPIPS 0.228; no self-generated-drift analysis.
- Long-term Spatial Memory (Wu, NeurIPS'25, 2506.05284): TSDF-fused static map from CUT3R; render through ControlNet into CogVideoX-5B + 5 recent frames + episodic keyframes; GT memory, no corruption. Reversed-trajectory revisit PSNR 19.1 vs 11.7-12.2. Admits artifacts when viewing generated content from very different poses.
- AlayaWorld v1.1 (2608.13492): point cache re-rendered along the planned trajectory; camera AdaLN branch REMOVED; invalid-render tokens removed, hard memory-token dropout; first rollout step without temporal memory. No ablation proving render obedience.

## B. Attention-token memory systems (rich temporal history; attention arbitrates)
- Lyra 2.0 (2604.13036, nv-tlabs/lyra): per-frame 3D caches, "never fuse into a single global point cloud"; greedy max-coverage selection of 5 spatial slots beside FramePack temporal slots + I0 in joint self-attention; canonical-coordinate warped maps in Q/K only. No masking/arbitration between spatial and temporal. Training: 64 GB200, 7,000 iters bs64; self-augmentation p=0.7, t~U(0,0.5) one-step denoise applied to the TEMPORAL history only; spatial slots and target clean; no on-policy rollouts. Camera = depth-warped last frame concat + Plücker MLP as fallback for uncovered pixels. Ablations: global fused cloud -> Cam Ctrl 49.9 vs 63.9; w/o self-aug -> Style 78.0 vs 85.1, Cam Ctrl 53.9. WorldCrafter re-measures Lyra 2 revisit LPIPS 0.487 / MEt3R 0.334.
- WorldCrafter (2609.24984): implicit encoder over k=9 max-coverage history latents, pose-guided readout; teacher-forced; revisit MEt3R 0.166 / LPIPS 0.255; raw-frame context ablation MEt3R 0.382; breaks on long trajectories.
- GEAR (2609.34722): history bank of latents + DA3 meshes -> token correspondences; Invisible Octree vetoes occluded matches; retrieved latents concatenated AND geometric correspondence attention; degraded-history aug on 40% of samples (tau~U(0,0.3), one reverse-flow step); LoRA r32, 10K it, 32 GPUs; frozen backbone; camera only through correspondences. Revisit SSIM 0.649 vs Spatia 0.441; w/o degraded history FVD 1166 vs 838.
- WorldMem (2504.12369): every frame written, no filter; FOV-overlap retrieval of 8 frames minus time penalty; memory attention block per DiT block, Plücker+time on Q,K; memory held at noise k_min=15 train+infer; zero-init gate decides; 10% memory dropout; beyond-context PSNR 24.0 vs DF 17.3. Context-as-Memory (2506.03141): 20 frames = first + latest + FOV-retrieved, latent-concat; 10% recent-only rows; PSNR 20.2 vs DFoT 17.6; error accumulation persists. VMem (2506.18903): surfel-indexed views, no filter; cycle LPIPS 0.397 (K=4) vs SEVA 0.401. SEVA (2503.14489): nearest-anchor selection by pose, always keeps the last generated anchor; admits saturation on non-overlapping paths and suggests noising input views at training.
- Robust Dreamer (2605.30855, no code): latent Gaussians carrying generated latents; names the write-recall loop ("small prediction errors contaminate the memory, bias subsequent denoising, and are repeatedly reintroduced"). Deviation Archive: one-step deviations indexed by AR index x timestep, Z=500, l2 dedup, injected into GT history BEFORE Gaussian construction p=0.9, clean target. LoRA r128, 8 H200, ~31 h/stage. Ablation ScanNet 80f SSIM: full 0.651, clean memory 0.268, Gaussian noise 0.275 -> structured corruption, not noise, is what works. Limits: unreliable geometry, not end-to-end.
- GeoVerse (2609.35734): confidence-weighted colored cloud, generated views scale-aligned and fused; observed and synthesized weighted equally; admits drift accumulates through spatial memory updates. WonderWorld: frozen old Gaussian layers, new layer per outpaint, guided depth aligns new depth to rendered opacity>0.6. ChronoWorld (2610.06687): the only explicit write gate (states pruned by Sampson/motion/photometric score before KV insertion). Memorizon (Wan2.2-5B): frustum-overlap retrieval, revisit = Pearson minus control pairs. Echo-Memory (2606.09803): "inject-none" variant gets the best replay PSNR while withholding memory -> replay metrics do not prove memory use. BAgger (2512.12080): reversed own rollouts as corrective data, drift ΔImaging 7.34 -> 3.57.

## Cross-cutting findings
1. Nobody documents an arbitration rule between memory and recent history. Systems whose memory is demonstrably obeyed either have almost no temporal history (GEN3C 1 frame, Voyager half-overlap, Mirage 1 chunk, Robust Dreamer 1 latent, MoVerse 3 local) or corrupt ONLY the temporal history during training while memory stays clean (Lyra 2, GEAR); both published ablations show large gains.
2. Camera through the render is the field's default (GEN3C, Voyager, ViewCrafter, Matrix-3D, Mirage, MoVerse, Robust Dreamer, AlayaWorld v1.1); Lyra 2 calls Plücker a fallback. Our camera-route finding is the norm, not a defect.
3. Persistent fused maps hurt: Lyra 2 ablation (Cam Ctrl -14) and our persistent-map result agree; GEN3C/Lyra keep per-frame caches with coverage selection; GEN3C aligns new depth to the cache render and noises old buffers by age.
4. Only Robust Dreamer corrupts the memory itself; only ChronoWorld gates writes; no one filters by confidence (GeoVerse weights synthesized = observed). Drift through memory is admitted by GeoVerse, Robust Dreamer, Wu et al., WorldPlay, CaM.
5. Revisit metrics: return-pass vs first-pass (WorldPlay MEt3R 0.133; WorldPlay2 RevisitBench PSNR 19.71 / LPIPS 0.318 / MEt3R 0.105; WorldCrafter MEt3R 0.166; VMem cycle LPIPS 0.397; Mirage PSNR_C 20.05; Wu reversed-path PSNR 19.10).

## Agent's ranked implications for us
1. Asymmetric-reliability training rows: corrupt or delete the temporal history, keep the scaffold clean, clean GT target. Missing pieces vs our Lyra-style self-aug: (a) rows with history tokens REMOVED entirely (p~0.3) so the scaffold is the only carrier; (b) heavier history noise (t~U(0.3,0.8)) than scaffold noise. Augmentation only; fits 200 updates. Measure with contradiction probes and revisit metrics, not replay LPIPS (Echo-Memory warning).
2. Write policy = Lyra/GEN3C, not a fused map: per-call rebuild from max-coverage-selected endpoints, new depth rigidly aligned to the current cache render masked by validity, older sources down-weighted/noised by age; keep validity/confidence channels as the evidence state. Zero training. ChronoWorld is the only published write gate and it is appearance-free (possible claim location).
3. Robust Dreamer deviation archive on the scaffold input (inject own one-step deviations into the frames that feed DA3/ReSplat before rendering; clean target). Single paper, no code, clean ablation; run after 1 and 2.
Corollary: stop trying to make camera embeddings carry translation; the field obeys camera through the render.

## Final consolidated report (same agent) — additions over the interim
- GEN3C write detail: Cache3D_Buffer.update_cache renders the existing cache at the new pose, aligns the new frame's MoGe depth to the rendered depth (rigid scale+shift, Eq. 4-5, or ARAP), unprojects and appends; Cache3D_BufferSelector picks top-K views by mask overlap; inference-time per-buffer noise scaled by age (newest 0).
- Voyager: implicit camera embedding called "nontrivial to train"; WorldScore 3D-consistency RGB-only 68.9 -> RGB-D 78.6 -> full 81.6.
- Robust Dreamer: deviation D = one Euler-step residual, indexed by AR index x timestep, 500 slots, l2-dedup; GT history corrupted X+D with p=0.9 BEFORE Gaussian construction, clean target, clean-input rows p=0.5. ScanNet 80f PSNR/SSIM: full 16.89/0.651 vs clean-memory 14.10/0.268 vs Gaussian-noise 14.25/0.275; 300f FID 16.8 vs 48.2.
- WorldMem: training retrieval = pose-radius random frames from the same GT video, 10% dropout to a single random frame. VMem: retrieval ablation surfel > FOV > cam-distance > temporal (LPIPS 0.381/0.424/0.422/0.794). Context-as-Memory PSNR 20.22 vs FramePack 17.20.
- WorldWeaver (2508.15720): long-term memory keeps depth clean and re-noises RGB/flow at t=0.8 ("trust geometry, not appearance" write). WonderWorld: the only system where frozen old geometry works, because nothing is ever re-generated over it (holes only).
- Echo-Memory: "Spatial inject-none" (memory stored but not fed) gets the best replay bundle -> apparent memory gains can be regularisation; recommends return-aware auxiliary supervision and measuring read-out separately.
- Memorizon (2610.00544): Wan2.2-5B, PRoPE, 6k steps 32 H200, fold-back revisit correlation; admits exposure-bias cost.
- Cross-cutting: no explicit memory-vs-history arbitration anywhere (20 systems). Two strategies: (i) render is the only carrier and history <= 1 chunk/frame; (ii) both kept and the temporal history asymmetrically corrupted/dropped (Lyra 2 p=0.7, GEAR 40%, AlayaWorld hard dropout). Only CaM/WorldMem drop memory (10%) and they are the weakest revisit systems. Nobody reports a self-write drift curve vs call index.

### Final ranked implications (agent)
1. Asymmetric reliability training: on ~30-40% of rows remove the history latents entirely (sequence-length change, AlayaWorld style; first call memory-free) and on the rest one-step self-aug at t~U(0,0.5) on history only; scaffold/validity untouched; target clean. <= 200 updates.
2. Memory-side deviation corruption (Robust Dreamer archive) injected into endpoint frames BEFORE ReSplat (p~0.9; clean-input rows 0.5), clean target; paired with GEN3C/Mirage structure (history = last latent + I0 only, scaffold = sole long-range carrier).
3. Write gate without training: never globally fuse; align each new endpoint's DA3 depth to the current scaffold render (GEN3C align_depth) before it enters the thinned set; reject endpoints whose Sampson/photometric agreement with the render exceeds a threshold (ChronoWorld prune); age-scaled noise on older sources at read time. Our M2 affine alignment sits on this axis; the geometric reject is the untested half.
Not recommended: frozen persistent Gaussians with write-only-new; any memory-token dropout.
