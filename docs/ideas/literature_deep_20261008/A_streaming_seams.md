# Report A — Chunk-boundary seams and long-horizon drift in streaming video diffusion (subagent, 2026-10-08)
V = verified in paper/code by the agent; I = inferred. Cloned repos in the session scratchpad.

## Cross-cutting finding (V)
Every Self-Forcing-lineage system (Self-Forcing, SF++, LongLive, Matrix-Game 2.0, Krea, WorldPlay2) does nothing special at the boundary in the sampler: each new 3-latent block starts from pure N(0,I) at t=1000 (shift 5), history enters only as a KV cache of clean (t=0) re-encoded features (`context_noise: 0` in every shipped config), no overlap, no re-noising. Seamlessness is learned: the video-level DMD loss from a bidirectional teacher is applied to the whole 21-latent self-generated rollout, so the teacher's score penalises boundary discontinuities directly, and the student has seen its own history during training. The only methods that fix the boundary in the sampler are Rolling Forcing (overlapping progressive-noise window), Diffusion Forcing/DFoT (history at small noise), MAGI-1 (pipelined monotone noise + 5% context noise + prev-guidance), StreamDiT (buffer with per-frame noise) and FramePack (pixel crossfade + clean anchors).

## Per method
- CausVid (arxiv 2412.07772): block-causal mask; 4-step student; asymmetric DMD from bidirectional teacher; ODE-regression init then 6000 DMD it, ~2 days on 64 H100. Boundary: KV cache of clean chunk at t=0. Weakness: over-exposure at 50 s (Visual Stability 40.47).
- Self-Forcing (arxiv 2506.08009, github guandeh17/Self-Forcing): rollout 7 blocks x 3 latents with KV cache during training; 4 steps; one random step keeps grad; after each block the clean x0 is re-run at t=context_noise(=0) to write KV. DMD timestep uniform over the whole 21-latent clip (holistic loss). Wan2.1-1.3B, real score 14B, 64 GPUs ~1.5 h. Rolling KV cache with local_attn_size/sink_size. Admits degradation beyond trained length. No boundary metric.
- Self-Forcing++ (arxiv 2510.02283): long rollouts (100 s) with rolling KV cache during training; DMD on a sampled teacher-length window; backward noise initialization (re-noise the student's clean latents as start noise); no sink; GRPO with flow reward. Visual Stability at 50 s 90.94 vs SF 40.12.
- Rolling Forcing (arxiv 2509.25161, github TencentARC/RollingForcing): window of 5 blocks at noise levels [1000,800,600,400,200]; every DiT call denoises the whole window jointly; only the newest block is pure noise; only the cleanest block is written to the clean KV cache; attention sink re-RoPEd to a fixed small relative distance. Training alternates single-frame and rolling objectives 50/50, 3000 steps, teacher 14B. Drift (first vs last segment quality) 0.01 vs SF 1.66, CausVid 2.18. Strongest direct evidence that overlapping joint denoising removes boundary/drift artefacts.
- LongLive (arxiv 2509.22622, github NVlabs/LongLive): Wan2.1-1.3B, local_attn_size 12, sink_size 3, LoRA r256, 64 H100 ~12 h, 240-latent rollouts. Streaming long tuning: each 21-latent loss chunk = overlap (0-3 latents of previous output) + new frames from pure noise; only new frames get gradient; the overlap's first latent is decoded and re-encoded as an image latent to match Wan's first-latent statistics. KV-recache. Quote: "attention sinks become effective once long-rollout collapse is addressed".
- Matrix-Game 2.0 (arxiv 2508.13009): SkyReels-V2-I2V-1.3B, Self-Forcing DMD, 3 steps, local_attn_size 6, sink 0, context_noise 0; streaming causal VAE decode with persistent vae_cache across blocks. Admits content consistency remains challenging without explicit memory.
- Infinite-World (arxiv 2602.02393): Wan2.1-1.3B + pose-free memory compressor; memory collapses beyond trained context, fixed by finetuning at longer context.
- WorldPlay / HY-World 1.5 Context Forcing (arxiv 2512.14614): chunk = 4 latents = 16 frames; memory = 3 temporal chunks + 1 spatial chunk + first chunk as sink; temporal reframing (context at fixed small relative positions); training noise for memory context sampled from [0, 0.2], targets [0,1]; each chunk from N(0,I); student self-rolls 4 chunks; bidirectional teacher with the same memory; DMD. Long-term PSNR 18.94 vs 16.27 without. Admits error accumulation is open.
- WorldPlay2 / Stable Forcing (arxiv 2609.35560, github Rising0321/WorldPlay2): Wan2.2 I2V-A14B, chunk 4 latents, memory tokens from learned compressor, temporal anchor = last 2 HR latents, optional sink. Stable Forcing = PDD few-step init (4 NFE), full-rollout replay with one cached intermediate step per chunk replayed with grads, per-clip DMD scores over 320-latent rollouts. RevisitBench LPIPS 0.318 / MEt3R 0.105.
- Krea Realtime 14B: Wan2.1-14B, SF DMD; drift fixes: periodic KV cache recomputation, KV attention bias (negative bias on past-frame tokens), first-frame anchoring, shorter context.
- StreamDiT (arxiv 2507.03745): buffered flow matching with per-frame noise levels; admits "slight seams or flickering may be observed between decoded chunks" and proposes overlap decoding -> the VAE decode, not only the DiT, can be a seam source when chunks are decoded separately.
- Diffusion Forcing / DFoT (2407.01392, 2502.06764): per-frame noise levels; stabilised rollout keeps history at small nonzero noise (k=0.02); history guidance with history noised to 0.4.
- MAGI-1 (2505.13211): 24-frame chunks, pipelined monotone noise, up to 5% noise injected into clean chunks in training "to alleviate exposure bias", loss only on noisy chunks; "perceptible misalignments between adjacent chunks" fixed by raising previous-chunk guidance w_prev to 1.5 and scheduling it by timestep.
- FramePack (2504.12626, github lllyasviel/FramePack): not causal; sections of 9 latents from pure noise; history as separate clean tokens (1x/2x/4x compressed) with own RoPE indices, never noised; inverted anti-drifting (sections generated end-to-start so the user image is always the clean anchor); pixel-level linear crossfade over overlapping decoded frames; drift metric |M(first 15%) - M(last 15%)|; fine-tune 8xA100 LoRA.

## Adapting a bidirectional Wan2.2-5B cheaply
Full causal conversion needs teacher + fake-score + rollout stack (not cheap). Cheap no-DMD routes used in the literature: (a) flow-matching fine-tune with per-frame timesteps and noised context (loss on target chunk only: MAGI/WorldPlay/DFoT style); (b) sampler-only changes (Rolling Forcing window, DF stabilisation, FramePack anchors/crossfade, Krea bias). Wan2.2 TI2V-5B already uses a t=0 conditioned latent for its image condition (I).

## Implications for a 4-latent-per-call bidirectional sampler with a 3D scaffold (agent's ranking)
Diagnostic first: decide whether the seam is in latents or only after decode (boundary/interior ratio on latent differences vs pixels; one call with raw history latents). StreamDiT shows independent chunk decoding alone produces seams; Matrix-Game 2.0 and WorldPlay2 decode with a persistent causal-VAE cache.
1. Overlap co-denoising of the last 1-2 history latents, sampler only: carry the last latent of the previous call into the new call as a target: at each step x_t = (1-s_t) x0_hist + s_t eps (RePaint/SDEdit-style, scalar timestep) or at small fixed noise with per-frame t; then crossfade. Evidence: Rolling Forcing, DF/DFoT, StreamDiT overlap decoding, FramePack crossfade. Cost +1 latent per call, no training.
2. Permanent clean anchor + reframed positions, sampler only: keep the real first frame as a clean t=0 frame at a fixed small relative temporal position; slightly stronger weight on the previous chunk at the boundary (MAGI w_prev 1.5). Caveat: sinks help only once rollout collapse is otherwise controlled (LongLive).
3. Cheap flow-matching fine-tune with noised self-generated history and per-frame timesteps, LoRA-scale: history latents from own rollouts at sigma_hist ~ U[0,0.2] (WorldPlay) / <=5% (MAGI) / 0.02 (DFoT), loss on target only, random 0-3 overlap latents (LongLive schedule), same small history noise at inference. Expect it to reduce the seam and slow, not eliminate, drift.
