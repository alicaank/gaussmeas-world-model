# Report D — Geometry Forcing, WorldForge and relatives (subagent, 2026-10-08; V = read in paper/code, I = inferred)

## Geometry Forcing (2507.07982, ICLR 2026; github CIntellifusion/GeometryForcing)
Base DFoT (U-ViT3D-pose, per-frame Diffusion-Forcing noise, ray-encoding camera). Teacher VGGT-1B aggregator outputs of all 24 layers on clean GT frames at 518^2, resized to 512x512 maps. Student tap = output of the 3rd down-level (paper "layer 3 of 7") at noisy x_t; conv projector (2x conv3x3 + pool + 1x1 -> 24). Losses: angular = -cos (global per layer in code) weight 0.5; scale = MSE of a small head on the normalised projection, weight 0.05 (code: alignment_coeff 0.1 x (angular + scale)); direct MSE collapses (FVD 1648), angular-only 253, both 243. Training 2,500 steps lr 8e-6 batch 8 on RE10K 10k clips, 8xA100; VGGT encoding = 53% of step time. Inference unchanged. Metrics RE10K 256-frame: FVD 364 -> 243, LPIPS 0.55 -> 0.51, RPE (DROID-SLAM reprojection) 0.358 -> 0.334, RVE (rFID first vs last after a full rotation) 297 -> 272; user-rated camera following 4.40 vs 3.3-3.6; DINOv2 teacher 297, Pi3 309. No camera translation/rotation error, no chunk-seam metric. Limits: VGGT static bias on dynamic scenes, flicker on reflective surfaces.

## WorldForge (2509.15130; CVPR 2026 highlight "Taming Video Models for 3D and 4D Generation via Zero-Shot Camera Control"; github Westlake-AGI-Lab/WorldForge)
Base Wan2.1-I2V-14B (diffusers fork), UniPC 50 steps, CFG 4, single 49-frame clip, no chunking. Warp: VGGT depth/pose -> point cloud -> render along scripted paths with validity masks (soft 15-px ramp). No inversion.
- IRR (intra-step recursive refinement): for steps < guide_steps (15-18 of 50), 2 rounds: normal CFG step -> x0-hat -> VAE decode -> pixel blend ref*M + gen*(1-M) -> VAE encode -> used as x0-hat; re-noised to the current sigma and the step recomputed. RePaint-style data consistency at x0, not a guidance scale. +40-50% time (17.3 min per 720p video on A100).
- FLF (flow-gated latent fusion): per latent channel, Farneback flow on the channel maps of the warped reference and x0-hat; channels whose motion disagrees (similarity < mean - 0.625 std; 0 at steps <= 5, up to 6 later) get the model's own x0 channel back, i.e. guidance withheld. The "camera vs object motion" separation is only this channel-level flow agreement.
- DSG (dual-path self-corrective guidance): good = guided velocity, worse = unguided; better = good + w * sin(theta) * (good - (|good|/|worse|) cos(theta) * worse); w 4-6, "too high causes artifacts"; cos between paths 0.3-0.6. CFG-formula control: FID 120.9 vs 96.1, "severe artifacts". Ablation FVD: w/o DSG 109.4, w/o FLF 112.7, w/o both 113.1, full 93.2.
- Metrics: FID/FVD, CLIP, ATE/RPE via evo after Sim(3) (pose tool not named). 3D: FID 96.1 / ATE 0.077 vs See3D 123/0.091, ViewCrafter 117.5/0.236. h-control measures WorldForge on RE10K: FVD 158.5, ATE 5.88 cm. No limitations section; no saturation discussion.

## Relatives
- Spatial Forcing (2510.12276): VLA, VGGT tokens cosine at layer 24/32.
- M2-REPA (2605.01896): DFoT; DINOv2 + DepthAnythingV2 + SAM2 through decoupled MLPs at early layers; 200-frame FVD 262 vs GF 408.
- GIM-World (2606.02436): Wan2.1; fixed memory tokens + camera-queryable geometry head distilled from VGGT (cosine, 0.05); reprojection score 81.7 vs generator-side GF 63.4: "constraining the memory beats constraining the generator"; 1000-frame rollouts.
- FantasyWorld (2509.21657): frozen Wan2.1 first 16 blocks + VGGT-initialised geometry branch with bidirectional cross-attention; WorldScore 3D-consistency 83.3; 64-112 GPUs.
- Geo-Align (2605.23903): GRPO with MapAnything metric-pose reward on ReDirector; TransErr 0.313 -> 0.308; 64 A800 x 130 h.
- WorldWarp (2512.19678): Wan2.1-1.3B fine-tuned 10k steps; online 3DGS cache; warped regions partial noise tau=0.8, holes sigma~1; chunks of 49 with 5-frame overlap; RE10K frame-200 PSNR 17.1 vs DFoT 15.2; RotErr 0.70 vs VMem 1.13.
- Warp-as-History (2605.15182): frozen Helios; warp as pseudo-history tokens with the target RoPE index + visible-token selection; zero-shot WorldScore camera 61.3 vs 26.4; +7.8 s per 33-frame chunk.
- Closing the Loop (2607.21848): causal Wan-VACE; pose-retrieved KV chunk + Gaussian attention bias from depth reprojection; revisit matches 49.1 vs Self-Forcing 23.3.
- h-control (2605.11871), on Wan2.2-TI2V-5B: hard replacement of warped latents at observed sites + block-conditional pseudo-Gibbs refinement (J_max 10 inner passes at steps 2-5 of 50, CFG 4); RE10K FVD 129.3 / ATE 3.49 cm vs WorldForge 158.5 / 5.88; its "Coarse-Guided" baseline (global noise-aware soft pull toward the warp = closest to our additive residual + CFG) 157.1 / 3.57; failure = faithfully tracks wrong depth.
- Time-to-Move (2511.08633): SDEdit init from the noised warped reference + dual clock (t_weak, t_strong) = (46, 41)/50, re-injecting the masked region noised to t-1; zero extra cost.
- No "depth/point/3D forcing" for video; no WorldForge v2 (README teases a unified world model).

## Implications (agent)
(i) GF-style alignment in <= 400 updates: ~1M-param projector + cosine loss on precomputed VGGT/DA3 features of clean targets, mid block (~10-15 of 30); expect partial effect at 1k clips; their ablations support long-horizon quality collapse and 3D consistency, never seams, translation magnitude or memory trust. GIM-World suggests aligning the MEMORY pathway (scaffold residual) to VGGT features so the model must read geometry from the scaffold.
(ii) Closest component to "initialise/guide each chunk from the scaffold": IRR masked x0 pixel replacement + resample, early steps, soft visibility mask; FLF withholds disagreeing channels; DSG amplifies only the orthogonal component. Their CFG-formula control is our failure regime. h-control on our base: masked hard replacement + refinement beats a global soft pull. None addresses chunk seams; only WorldWarp (trained, 5-frame overlap) and AlayaWorld do.
(iii) 35-min experiments: GF geometry probe (ridge map from block features to VGGT/DA3 features, trunk vs scaffold pathway); DSG drop-in replacing scaffold CFG (w 2/4, steps 1-12 of 30, log cos theta); IRR-lite (one resample at steps 2-6 with x0 pixel blend of the scaffold render in covered pixels).
